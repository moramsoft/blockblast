# 블록 블래스트 스타 (Block Blast Star) ⭐

전 세계 구글 플레이 스토어 캐주얼 부문 1위를 휩쓴 대세 퍼즐 게임 **블록 블래스트(Block Blast)**를 웹 브라우저에서 즉시 플레이할 수 있도록 완벽하게 구현한 카피 프로젝트입니다.

---

## 🎮 게임 특징 및 핵심 메커니즘

1. **8×8 그리드 퍼즐**:
   - 하단 트레이에 등장하는 3개의 다양한 블록(테트로미노, 펜토미노, 대형 L, 3×3 등)을 8×8 그리드에 자유롭게 배치합니다.
   - 가로 또는 세로 한 줄을 완전히 채우면 시원하게 폭발하며 블록이 클리어됩니다.
   - 3개의 블록을 모두 놓으면 새로운 3개의 블록 세트가 주어집니다.

2. **중독성 넘치는 콤보 & 스트릭 시스템 (Combo & Streaks)**:
   - 블록을 놓을 때마다 연속으로 라인을 제거하면 **콤보 스트릭**이 발동합니다.
   - 콤보가 올라갈 때마다 신나는 칭호와 함께 스코어 배수가 기하급수적으로 증가합니다:
     - 1줄: `COOL!`
     - 2줄: `GREAT!`
     - 3줄: `CLEVER!`
     - 4줄: `SUPERB!`
     - 5줄+: `UNBELIEVABLE!`
   - 콤보가 올라갈수록 펜타토닉 음계로 상승하는 영롱한 신디사이저 사운드 이펙트가 울려 퍼집니다.

3. **고급 손맛 & 피드백 (Juice & Polish)**:
   - **보석 블록 3D 셰이딩**: 그라데이션, 하이라이트 광택, 입체 베벨 효과.
   - **라인 클리어 파티클 폭발**: 클리어된 블록들이 보석 파편과 별빛 파티클로 사방으로 폭발.
   - **화면 흔들림 (Screen Shake)**: 멀티 라인 클리어 및 고콤보 시 타격감 넘치는 카메라 셰이크.
   - **배치 전 라인 클리어 미리보기 (Glow Preview)**: 블록을 올려놓았을 때 터지게 될 라인이 황금빛으로 번쩍이며 미리 안내됩니다.
   - **놓을 수 없는 블록 표시**: 그리드에 들어갈 자리가 없는 블록은 반투명하게 어두워져 직관적으로 파악 가능.

4. **모바일 & 데스크톱 완벽 지원 (Mobile UX First)**:
   - 모바일 터치 시 손가락/엄지에 블록이 가려지지 않도록 **수직 오프셋(Vertical Finger Offset)** 자동 적용.
   - 고해상도 레티나 디스플레이(HiDPI) 대응으로 칼같은 렌더링 품질.
   - 키보드 단축키 지원: `M` (음소거 토글), `R` (재시작).

5. **자체 Web Audio API 절차적 사운드**:
   - 외부 오디오 파일 다운로드 없이 100% 브라우저 내장 Web Audio API로 실시간 음향 합성 (빠른 로딩, 지연 없는 타격음).

6. **1회 부활 (Revive) 보너스**:
   - 게임 오버 시 1회 한정으로 중앙 4×4 영역을 폭파하여 역전의 기회를 제공합니다.

## 🚀 실행 방법

### 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173/` 접속

### 프로덕션 웹 빌드
```bash
npm run build
npm run preview
```

## 📱 안드로이드(Google 앱) 빌드 및 설치

### 1. 생성된 빌드 산출물 (즉시 설치 가능)
- **APK (안드로이드 기기 직접 설치용)**: `build-artifacts/BlockBlastStar.apk` (약 3.9MB)
- **AAB (구글 플레이 스토어 배포용 번들)**: `build-artifacts/BlockBlastStar.aab` (약 3.4MB)

### 2. 안드로이드 기기 또는 에뮬레이터에 설치 (`adb`)
```bash
adb install build-artifacts/BlockBlastStar.apk
```

### 3. 새롭게 안드로이드 빌드 실행
```bash
# APK 빌드 (자동 웹 빌드 + 동기화 + Gradle 빌드)
npm run build:apk

# Google Play 스토어용 AAB 빌드
npm run build:aab

# Android Studio에서 프로젝트 열기
npm run open:android
```
